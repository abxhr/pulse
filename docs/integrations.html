Integrations

Everything is optional and everything stays on your machine. The demo needs none of it.

Garmin

Pulse pulls sleep and stages, HRV, training readiness, body battery, stress, SpO2, respiration, resting HR, VO2max, steps and every activity using the garminconnect library.

cd backend
python -m app.auth_garmin

Run it once. It handles 2FA and caches tokens in backend/data/garmin_tokens (git-ignored). Optional GARMIN_EMAIL and GARMIN_PASSWORD in .env are used only by that one-time step.

Hevy (no Pro needed)

HEVY_MODEWhat it is
csvReliable. Export from Hevy (Settings, Export & Import Data, Export Workouts), then drop the file in backend/data/imports/, upload it with Import CSV in the app, or run python -m app.import_hevy file.csv.
unofficialHands-off sync through the private endpoints Hevy's own web app uses. Experimental and can break; CSV always works as a fallback. One-time login: pip install "hevy-unofficial[core]", python -m playwright install chromium, then cd backend && python -m app.hevy_auth. A browser opens at hevy.com and you log in there; your password goes straight to Hevy, never through Pulse.
proThe official API, if you have Hevy Pro: set HEVY_API_KEY.
autoThe default: Pro key if present, else a saved login, else CSV.

AI Coach

Set AI_PROVIDER to anthropic or openai and add the matching key. The model only receives a compact summary (daily aggregates and trends, not raw records). Without a key, the rest of Pulse works as normal.

Weather and reminders

Set LATITUDE and LONGITUDE for a weather card from Open-Meteo, which needs no key. For background push reminders run python -m app.generate_vapid_keys and follow what it prints.

Keep secrets out of git. Your keys live in .env and your tokens in backend/data/. Both are git-ignored. Never paste either into an issue or a screenshot.
