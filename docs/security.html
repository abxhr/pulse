Privacy

Your health data lives in a SQLite file on your computer. The only thing that leaves is what you choose to send to an AI.

Where your data lives

In backend/data/pulse.db, plus cached login tokens next to it. That folder and your .env are git-ignored, so they never reach the repository. Pulse has no account and no cloud service of its own.

What goes to the AI

Only when you use the Coach or generate a report narrative, and only with your own key. It receives a compact JSON summary of daily aggregates and trends, not raw activity or sleep records.

Sign-in and protections

  • One password you choose (10 characters or more), stored as a salted scrypt hash. Setting or resetting it is only allowed from the computer running Pulse.
  • All health data and every change require sign-in. Failed logins are rate limited.
  • Strict browser headers, including a Content-Security-Policy, and restricted cross-origin access (CORS_ORIGINS).
  • Upload size limits, and backups you can take and restore locally.

What this site and repository contain

Only code and invented demo data. The screenshots come from a demo database created by python -m app.seed. If you fork it, keep .env and backend/data/ out of git; the included .gitignore already does.

Found a security problem? Please open an issue on GitHub without including any personal data.

Pulse is a private, single-user app that runs on your own computer. Every screenshot on this site comes from the built-in demo: an invented person, invented workouts, invented sleep. No real data appears anywhere in this repository. MIT licensed. Not medical advice.
