Set it up

Pulse runs on your own computer: a Python backend with a SQLite file, and a React frontend. Start with the demo data, then connect your own accounts when you like.

You need

  • Python 3.10 or newer, Node.js 18 or newer, and Git
  • Optional, for your own data: a Garmin account (a device that records sleep and HRV) and a Hevy account (free is fine)
  • Optional: an Anthropic or OpenAI API key for the Coach

1. Get the code

git clone https://github.com/abxhr/pulse.git
cd pulse

2. Install the backend

cd backend
python -m venv .venv
# macOS / Linux:
source .venv/bin/activate
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
pip install -r requirements.txt

3. Create your settings file

cd ..
cp .env.example .env      # Windows: copy .env.example .env

The defaults run as they are. .env is where any keys go later, and it is git-ignored so it never gets committed.

4. Load the demo data

cd backend
python -m app.seed

This fills a local database with 90 days of invented sleep, runs and workouts so you can look around before connecting anything. To clear it later: python -m app.seed --wipe, or delete backend/data/pulse.db.

5. Build the frontend and run

cd ../frontend
npm install
npm run build
cd ../backend
python -m app.main

Open http://localhost:8080 on the same computer. The first time, Pulse asks you to choose a password (at least 10 characters). Setting the first password is only allowed from the computer running Pulse.

Developing instead? ./dev.sh (or dev.bat on Windows) runs backend and frontend with hot reload, and the app is at http://localhost:5173.

6. Connect your own data

When you are done exploring, wipe the demo and connect real accounts:

  1. Garmin. Run cd backend && python -m app.auth_garmin once. It asks for your login and any 2FA code and caches tokens locally in backend/data/. Your password is not stored in .env.
  2. Hevy. Pick a mode with HEVY_MODE in .env. csv is the simplest. See Integrations.
  3. Coach (optional). Add ANTHROPIC_API_KEY or OPENAI_API_KEY to .env and set AI_PROVIDER.
  4. Restart the server and press Sync. With ENABLE_SCHEDULER=true it then keeps itself up to date.

Keep it running

SystemHow
WindowsPut a shortcut to backend/start_server_hidden.vbs in shell:startup. It runs start_server.bat with no console window.
Linux / Raspberry PiA systemd service running backend/.venv/bin/python -m app.main with Restart=always.

Troubleshooting

  • Garmin asks for MFA again. Re-run python -m app.auth_garmin.
  • Hevy CSV imported 0 workouts. Use the Workouts export, not a routines export.
  • Can't reach it from your phone. Check HOST=0.0.0.0, that you built the frontend, and that your firewall allows the port. See Phone.
  • Blank readiness or HRV. That needs a Garmin device that records them; very old dates may be empty.
